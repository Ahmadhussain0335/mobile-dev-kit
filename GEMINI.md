# mobile-dev-kit

This extension provides Agent Skills for Android, iOS and Flutter development in its `skills/` folder.
Activate a skill when the task matches its description; read a skill's `references/` files only when
its workflow says to.

- `mobile-code-review` -- review Kotlin, Java, Swift and Dart code and diffs
- `mobile-security` -- OWASP MASVS v2 audits, secure storage, TLS, IPC, EU compliance notes
- `mobile-ci-cd` -- GitHub Actions and GitLab CI pipelines, signing, store upload
- `mobile-merge-request` -- branches, Conventional Commits, MR descriptions, conflict resolution
- `mobile-mvvm` -- MVVM on Android, iOS and Flutter
- `mobile-mvi` -- MVI with reducers, effects and Bloc
- `mobile-mvc` -- UIKit MVC, Android MVP, migration to MVVM
- `mobile-design-patterns` -- choosing and applying design patterns without over-engineering
- `kotlin-android` -- modern Kotlin, coroutines, Flow, Compose
- `java-android` -- Java on Android and migration to Kotlin
- `swift-ios` -- Swift 6, SwiftUI, SwiftData, Swift Testing
- `dart-flutter` -- Dart 3 and Flutter
